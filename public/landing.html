[ FEATURES ]
EVERYTHING IN ONE PLACE
◕
3D GLOBAL ATTACK MAP
Interactive globe showing live attack arcs from source to destination countries. Color-coded by severity with real-time AbuseIPDB data.
⚲
IP + CVE LOOKUP
Instantly query any IP against AbuseIPDB for abuse history, ISP, and reports. Search CVEs by keyword or ID via the NVD API with CVSS scores.
▤
ANALYTICS & HISTORY
7-day and 30-day attack frequency charts, top attacker countries, and severity breakdowns. Export to CSV with one click.
▫
LIVE THREAT FEED
Auto-classified news from The Hacker News, BleepingComputer, and CISA. Critical/warning/info tags updated every 5 minutes.
⚙
PERSISTENT CACHING
SQLite + file-based cache survives restarts. AbuseIPDB calls cached for 2 hours, IP reports for 1 hour, CVEs for 6 hours.
☮
DOCKER READY
Single docker compose up to run anywhere. Alpine-based image, named volumes for cache persistence, env-based config.

[ SETUP ]
GET RUNNING IN 2 MINUTES
DOCKER (RECOMMENDED)
$ git clone https://github.com/artemusuni/CyberDashboard
$ cp .env.example .env # add your AbuseIPDB key
$ docker compose up
LOCAL
$ npm install
$ node server.js

Requires a free AbuseIPDB API key. The setup wizard guides you through configuration on first run.
